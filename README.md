# MINI--PROJECT
# Fingertip Tissue Deformability-Based Non-Invasive Anemia Detection Device

## Project Overview

This project presents a non-invasive anemia screening system that estimates anemia risk using fingertip tissue deformability and optical sensing techniques. The system combines pulse sensing, pressure measurement, and embedded signal processing to provide rapid and low-cost preliminary anemia screening.

## Objectives

* Detect anemia without blood extraction.
* Analyze fingertip tissue deformability under controlled pressure.
* Measure optical signal variations using a pulse sensor.
* Provide real-time results using an LCD display.
* Develop a portable and affordable healthcare screening device.

## Hardware Components

* Arduino Uno (ATmega328P)
* Heart Pulse Sensor Module
* Load Cell
* HX711 Amplifier Module
* 16x2 LCD Display
* Push Button
* Breadboard and Power Supply

## Working Principle

1. The user places a fingertip on the pulse sensor.
2. Optical signals are captured using photoplethysmography (PPG).
3. Controlled pressure is applied and measured using a load cell.
4. The Arduino processes optical and pressure data.
5. Signal processing algorithms estimate anemia-related variations.
6. Results are displayed on the LCD screen.
